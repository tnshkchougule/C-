## Program
### Odd or Even Number

This program checks whether a given integer is odd or even.

### Logic
- If the number is divisible by 2, it is **Even**.
- Otherwise, it is **Odd**.

## Concepts Used
- Input and Output (`scanf`, `printf`)
- `if-else` statement
- Modulus (`%`) operator
